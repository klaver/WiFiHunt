# WiFiHunt: digitale vossenjacht (foxhunt)

In deze repository vind je de benodigde Arduino code om de WiFi vosjes te kunnen programmeren voor het WiFiHunt spel. Speluitleg staat in dit PDF document: [WiFiHunt-spel.pdf](https://github.com/klaver/WiFiHunt/blob/main/WiFiHunt-spel.pdf). In de QR-Codes map vind je de bijbehorende WiFi-access codes voor de betreffende vosjes.

Geïnspireerd op diverse voorgaande projecten van anderen, waaronder die van Tjalling (PE1RQM).

Ik heb zelf gekozen om gebruik te maken van de WEMOS D1 ESP-WROOM-02 modules. Dit zijn kant-en-klare ESP8266 Nodemcu WiFi modules met een ingebouwde type-18650 batterijhouder (geen electronica soldeerwerk nodig). Onder andere verkrijgbaar bij AliExpress: https://s.click.aliexpress.com/e/_c3EYaalr
